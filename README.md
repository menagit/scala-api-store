# API Store

An e-commerce backend with REST and GraphQL APIs, built as a modular monolith. It is a practice project to get comfortable with a production-style Scala stack.

## Stack

Scala 2.13 (`-Xsource:3`), Play 3.0 on Pekko, MySQL 8.4, Relate, Flyway, circe, Sangria, JDK 17, sbt.

## Status

The architecture is decided for the foundations and for identity, and the decisions for catalog, shopping, ordering and payments are still open. Work starts with a walking skeleton and the identity context, and the other contexts follow as their decisions are made.
